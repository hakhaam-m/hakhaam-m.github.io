# Iman Mostalipour — Portfolio Site

Personal portfolio & undergraduate application site (Animation / Game Art, Romania).
Live at: https://hakhaam-m.github.io/

## Deploy (2 minutes)
1. On GitHub, create a **public** repository named exactly `hakhaam-m.github.io`
2. Upload all files and folders from this package (keep the structure: `index.html`, `portfolio.html`, `project.html`, `cv.html`, `styles.css`, `assets/…`)
3. Wait ~1 minute → the site is live at https://hakhaam-m.github.io/

## Edit
- Text lives in the `.html` files; colours in `styles.css` (`--red` is the accent).
- Images are in `assets/`; replace a file with the same name to swap an artwork.
